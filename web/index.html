    LLM-Endpunkte

    Lokale Modelle via Ollama (Standardport 11434) oder OpenAI-kompatibel (MLX, LM Studio …). CORS auf dem Server muss erlaubt sein — für Ollama z. B. OLLAMA_ORIGINS=*.

      + Endpunkt hinzufügen
      Reasoning-Default

      Wird pro Wurf in der UI überschrieben. „Auto" = keine Steuerung, Modell entscheidet selbst. „An" / „Aus" setzt für jede Anfrage den passenden Parameter (Ollama: think, OpenAI-kompatibel: reasoning_effort + chat_template_kwargs).

      Beratungs-Prompt

      System-Prompt für die Interpretation. Wird mit Würde-/Mitgefühls-Default vorbelegt.
